# CORNER project rules

- Keep CORNER Android-first, accessible, and usable without backend credentials or user photos.
- Use approved, low-impact home movements by default. Keep higher-intensity catalogue images out of beginner programming unless reviewed.
- Nutrition content must be vegetarian and contain no eggs, meat, fish, seafood, or poultry. Do not add restrictive dieting, calorie targets, or weight-loss guidance.
- Never provide diagnosis, train-through-pain guidance, or fighting instruction.
- Never put provider secrets in Expo/client code. Admin permissions must be enforced by a trusted backend.
- Preserve rest and missed sessions without punitive streak resets.
- Run `npm run typecheck`, `npm run test:logic`, and `npm run assets:sync` when relevant changes are made.
